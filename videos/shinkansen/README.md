# 見せてもらおう！新幹線の実力を…… — 動画生成

「余命1年の少年」(../noah_hanabi) と同じ体裁(上下黒帯・半透明帯の白字幕・女性ナレーター1人・
冒頭のドーン音+近づく決めゼリフ・CTA動画・グリーンバックの終了画面)で作る。

## 作り方

1. 環境設定で `PEXELS_API_KEY` を登録した新しいセッションで実行する(https://www.pexels.com/api/ で無料発行)
2. `videos/make_video.sh videos/shinkansen pexels`
3. `out/clip_choices.json` の各ショットを目で確認し、合わないものは `overrides.json`
   (`{"b02_1": <PexelsのID>}`) で差し替えて `pick_clips.py` → ダウンロード → `render3.py` をやり直す
4. 完成品 `out/video_1080p.mp4` を gofile.io などで受け渡す(30MB 超はチャットで送れない)

## このフォルダのファイル

- `script.txt` … 台本(音声入力の変換ミスを修正済み。修正点は下記)
- `video_queries.py` … 台本の各ブロックで使う Pexels の検索語
- `readings.json` … 読み上げの読み替え(TGV→ティージーブイ、浩司→こうじ など)
- `assets/` … CTA動画・終了画面・冒頭の効果音(チャンネル共通)

## 台本の修正点

時計をやりました→時計に目をやりました / 腕時計を落とす→腕時計に目を落とす / 社外へ→車外へ /
鉄道企画→鉄道規格 / 国境を超える→越える / 写真を取ってくる→撮ってくる / 技術をつぐ→つなぐ /
思考錯誤→試行錯誤 / 疑わずに住む→済む / 前日大阪市内のホテル→その夜、大阪市内のホテル /
東京外の国分寺→東京郊外の国分寺 / 951型→951形 / メモリ→目盛り / 持場→持ち場 /
後方台や分散した動力→高頻度ダイヤや分散した動力(推測) / 着いた美咲は→美咲は /
「綺麗なカードね」→「綺麗なカードだね」(アランのセリフのため) / 東京の町→東京の街 /
