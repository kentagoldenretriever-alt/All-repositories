サムネ制作の仕組み（パッケージ）

■ 最初にやること（これだけ）
1. このフォルダを、Claude（デスクトップアプリの Code タブ、またはターミナルの claude）で開く
2. 「セットアップして」と伝える
   → 最初に必要な情報をまとめて聞かれます（下の「答えを用意しておくもの」）
   → あとは確認しながら、設定・テンプレの読み込み・動作確認・定期実行の登録まで進みます
   → 最後に使い方の説明が表示されます

■ 先に入れておくもの
- Mac または Windows のパソコン
- Photoshop 2025/2026（Creative Cloud にログイン済み）
- 自分のチャンネルのサムネテンプレ（PSD）で使っているフォント（Adobe Fonts で有効化）
- 画像生成用の Codex（ChatGPT アカウントでログイン）
  Mac＝ChatGPT のデスクトップアプリに同梱／Windows＝セットアップ中に入れ方を案内します
  ※Windows は初回のセットアップで動作を確かめながら進めます
- Claude Code（有料プラン）
- Google Drive for desktop（案件の作業フォルダが見える状態）

■ 答えを用意しておくもの（セットアップの最初にまとめて聞かれます）
① チャンネル名
② チャンネルのURL
③ 管理シートのURL（案件一覧のタブ・編集権限をもらっておく）
④ リサーチシートのURL（元ネタURLと指定タイトルが入っているタブ）
⑤ 自動で着手してよい範囲（決めていなければ「上から10行目まで」）
⑥ 自分のチャンネルのサムネテンプレ（PSD）の場所
⑦ Google Drive の作業フォルダ（案件フォルダが並んでいる所）の場所
⑧ シートの鍵（Google のサービスアカウントの json）の場所（無ければ作り方を案内します）
⑨ 定期実行の時刻（例：毎日0時）
⑩ 1回に処理する最大件数（決めていなければ10件）
※YouTube の API キーは要りません（公開されている情報だけで調べます）。

■ セットアップ後
「サムネ作って」で今日の分を処理、「NO○○のサムネ作って」で1件だけ処理します。
詳しくは 使い方.md を見てください。
