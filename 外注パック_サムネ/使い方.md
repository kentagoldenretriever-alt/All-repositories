# サムネ制作の仕組み｜使い方

## これは何をするか
管理シートの上から順に、サムネが未完成の案件を1件ずつ処理します。

1. 元ネタ動画のサムネと、同じ題材で伸びている他社のサムネを集めて、「なぜ押されたか」を言葉にする
2. 3行のコピー（1行目＝黄色のセリフ／2行目＝状況／3行目＝結末）を、元ネタや他社の実際の言葉から決める
3. 中央画像を2〜3通り生成し（ChatGPTの画像生成）、Photoshopのテンプレに3行と記号を合成する
4. 3組300人のパネル（デザイナー・65歳以上の視聴者・コピー担当）で採点し、**加重平均90点**を目指して直す
5. 合格（または直しても新しい指摘が出なくなった）版を、案件フォルダに納品し、管理シートに完了日を書く

## 毎日の流れ
- 設定した時刻に自動で動きます（止めることもできます）。
- 終わると報告が出ます：処理した案件・3行・点数・納品先・残った課題・判断してほしいこと。
- **あなたがやること**：できたサムネを見る → よければ管理シートのチェック欄に✓ → YouTube Studioでサムネを設定・公開。
  （チェック欄・YouTubeへの設定・公開は、仕組みの側では触りません）

## 話しかけ方（Claude に言うこと）
| 言うこと | 起きること |
|---|---|
| 「サムネ作って」「今日の分やって」 | 管理シートの対象を上から全件処理 |
| 「NO46のサムネ作って」 | その案件だけ処理（上から10行の外でも可） |
| 「対象を見せて」 | 未完成の案件の一覧を表示 |
| 「みせて」 | 途中の候補・最高点の版を画像で表示 |
| 「この版で納品して」 | 90点未満でもその版で納品し、完了日を書く |
| 「チェック入れて」 | 管理シートのチェック欄に✓を入れる（言われた時だけ） |
| 「3行目を〇〇に直して」 | 文言を直して合成し直す |
| 「定期実行の時刻を変えて」「自動実行を止めて」 | 定期タスクの時刻変更・停止 |
| 「テンプレを替えたので合わせて」 | 新しいテンプレを解析して、行・記号・字数を合わせ直す |
| 「管理シートが変わったので直して」 | 新しいシートのURLを聞いて設定を直し、列の対応を確かめる |
| 「使い方を見せて」 | この説明を表示 |

## 納品されるもの（案件フォルダの中）
| ファイル | 中身 |
|---|---|
| `<NO> A.png` | 完成サムネ（1280×720） |
| `<NO> A.psd` | レイヤーを残したPhotoshopファイル（手で直したい時用） |
| `<NO> A_アップ用.jpg` | YouTubeにアップする用（2MB未満。PNGは2MBを超えるのでこちらを使う） |
| `サムネ/_eval.md` | 採点の経過（各周の点・指摘・終わった理由） |
| `サムネ/_元ネタ言語化.md` | 元ネタの分析と、3行の言葉をどこから採ったか |

## 点数の見方
- **90点以上＝合格**。85〜89は「続行可」、80〜84は「弱点を直して再採点」、79以下は作り直し。
- 90に届かなくても、直すたびに新しい指摘が出なくなったら「収束」として最高点の版で終わります（報告に点数と「90未達」を明記します）。
- 途中で「この版で納品して」と言えば、その時点の版で納品します。

## 費用と時間の目安
- 1件あたり：Claude のトークン **約30万**（採点1周あたり約10万×周数）・時間 **30〜60分**。
- 画像生成は ChatGPT 側（codex）で行うので、Claude のトークンはほぼ使いません。1枚2〜3分。
- 使いすぎが心配なら「1回に処理する件数」を減らすか、自動実行を止めて「NO○○のサムネ作って」で1件ずつ頼んでください。

## うまくいかないとき
| 症状 | 対処 |
|---|---|
| Photoshop が「フォントが見つからない」と出す | **「置換」を押さない。** Creative Cloud でテンプレのフォントを有効化してから、もう一度頼む |
| 画像生成が何分も返ってこない | 題材によって生成が止まることがある（入浴・子どもなどの語、否定形の指示）。Claude が言い換えて再実行します |
| 「フォルダが見つからない」「読めない」 | Drive が同期中か確認。Mac はフルディスクアクセスが外れていることがある（システム設定 → プライバシーとセキュリティ → フルディスクアクセスで Claude を許可） |
| シートに書けない | サービスアカウントのメールがシートの「共有」に編集者で入っているか確認 |
| 3行目の字が潰れている・右端が切れている | その行が長すぎる。字数の目安（セットアップで測った値＝`config.json` の `template.chars`）まで縮めて直してもらう |
| テンプレを作り替えた | 「テンプレを替えたので合わせて」と言う（セットアップの手順6だけやり直す） |

## やらないこと（仕組みの約束）
- テンプレPSDの原本を書き換えない
- チェック欄・YouTube・公開設定に触らない
- 鍵ファイルの中身やパスワードを表示しない
- 採点が終わる前に完了日を書かない
