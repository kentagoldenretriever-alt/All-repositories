# サムネ制作パッケージ｜このフォルダで作業するときの前提

このフォルダは、海外の反応系YouTubeチャンネルの**完成サムネ**（1280×720・3行テロップ入り）を、
元ネタの解析 → 3行コピー → 中央画像の生成 → Photoshopテンプレへの合成 → 3組パネルでの採点 → Driveへ納品 → 管理シートに完了日、
まで一気通貫で作る仕組みです。

## 言われたら、まずこれを読む
| 言われたこと | 読むもの・やること |
|---|---|
| 「セットアップして」「初期設定して」 | **`SETUP.md` を最初から最後まで読み、その手順どおりに進める**（飛ばさない・順番を変えない） |
| 「サムネ作って」「今日の分やって」「NO○○のサムネ作って」 | `config.json` があることを確認 → **`skill/SKILL.md` の手順どおりに進める** |
| 「使い方を見せて」 | `使い方.md` を表示する |
| 「対象を見せて」 | `<python> scripts/find_targets.py` の結果を表にして見せる（`<python>`＝config.json の `python`） |
| 「定期実行の時刻を変えて」 | `SETUP.md` の「手順8 定期タスク」をやり直す |
| 「テンプレを替えたので合わせて」 | 新しいテンプレの場所を聞き、`SETUP.md` の「手順6 テンプレを合わせる」をやり直す |
| 「管理シート（リサーチシート）が変わったので直して」 | 新しいURLを聞き、`config.json` の `sheet` のID・gidを直して `check_env.py` が全部 ✓ になるまで合わせる（`SETUP.md` 手順2・3・5-2）。鍵のメールを新しいシートに共有してもらう |

`config.json` が無いのに「サムネ作って」と言われたら、作らずに「先にセットアップが要る」と伝えて `SETUP.md` を始める。

## どこに何があるか
| 置き場所 | 中身 |
|---|---|
| `skill/SKILL.md` | 手順（何をどの順でやるか）＝**唯一の手順書** |
| `knowledge/採点基準.md` | 採点の基準（3組・加重平均90で合格） |
| `knowledge/thumbnail_copy_formula.md` | 3行コピーの型（実データで検証した正典） |
| `knowledge/サムネのルール集.md` | 作り方のルール（画・文字・記号・納品・詰まったとき） |
| `scripts/` | 合成器・記号ゲート・対象の抽出・材料集め・色の実測・納品・シート記入・環境チェック |
| `assets/` | 見本のPhotoshopテンプレ（原本・上書き禁止）・国旗画像。実際に使うのはチャンネルごとのテンプレ（`config.json` の `template_psd`） |
| `config.json` | このチャンネル用の設定（セットアップで作る）。`template` にテンプレのレイヤーの役割・各行の字数・写真が見える帯 |
| `data/` | 記号の配置履歴（消さない） |

★**同じルールを2か所に書かない。** 判定＝採点基準／作り方＝ルール集／手順＝SKILL.md。

## 絶対に守ること
- **Python は `config.json` の `python` を使う**（Mac＝`/usr/bin/python3`／Windows＝`python`）。Mac と Windows の両方で動く（Windows は Photoshop を COM で動かす）。
- **画像生成は codex 経由で、1件ずつ直列**（並行させると他の案件の画像を掴む）。
- **テンプレPSDの原本を上書きしない。** 合成器は開いて書き出し、保存せずに閉じる。
- **管理シートのチェック欄は、人が「チェック入れて」と言った時だけ触る。** 完了日は採点が終わって納品した後だけ書く。
- **YouTubeへのサムネ適用・公開設定はしない**（人がやる）。
- **パスワード・APIキー・鍵ファイルの中身を聞いたり表示したりしない。** 鍵ファイルは「置き場所のパス」だけを設定に書く。
- 自分の出力を信用しない。**画像は必ず開いて拡大して見る。** 数値が範囲内でも、絵が悪ければ絵が正しい。
